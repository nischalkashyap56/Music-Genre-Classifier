# Music-Genre-Classifier
A music genre classifier that factors in audio features and acoustic attributes such as tempo, MFCCs, spectral characteristics and other features to accurately classify a track into a particular genre.

## Installation

Clone this repository to your system with the following command in your Git GUI:

```
git clone https://github.com/nischalkashyap56/Music-Genre-Classifier.git
```
## Functionalities :
The following project is a music genre classifier that is implemented using Python as the programming language. Some of the functionalities implemented are :
```
1. Developing a Sequential model, with input, hidden and output layers using Keras.
2. Parsing the audio features as inputs into the Artificial Neural Network, and based on the output, classify them into corresponding genres of music.
3. Return a CSV file with the tracks and the accurately classified genres they belong to.
```
